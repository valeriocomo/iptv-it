# IP-TV playlist generator

Generates an Italian free-to-air IPTV playlist for Jellyfin, ready to publish on GitHub.

Each run:

1. downloads the upstream playlist from [Tundrak/IPTV-Italia](https://github.com/Tundrak/IPTV-Italia) (`iptvitaplus.m3u`);
2. refreshes the TV8, Cielo and Sky TG24 links with [yt-dlp](https://github.com/yt-dlp/yt-dlp), since Sky links carry a token that expires;
3. opens every link with the same User-Agent Jellyfin uses (`HbbTV/1.6.1`); a link that does not answer is replaced with a working official one: for RAI the same relinker link without the old parameters, otherwise a link from [iptv-org](https://github.com/iptv-org/iptv) (`streams/it.m3u`) that is not a third-party rebroadcast;
4. writes the result to `public/`, keeping the upstream file name (`public/iptvitaplus.m3u`).

The playlist is not generated automatically: you start it by hand, then commit and push the file yourself. The TV guide (`public/guide.xml`) is regenerated by GitHub Actions instead, see [Automatic TV guide update](#automatic-tv-guide-update).

## Requirements

- Docker with Compose.
- An Italian IP address: Sky live streams are geo-blocked outside Italy. Run it from the same network as your Jellyfin server if you can.
- A public GitHub repository, cloned on your computer.

## Files

| File | Purpose |
| --- | --- |
| `playlist/generate-playlist.js` | Downloads the upstream playlist, refreshes the Sky links, writes the output |
| `playlist/entrypoint.sh` | Updates yt-dlp, then runs `generate-playlist.js` once |
| `playlist/Dockerfile` | Node.js 26 on Alpine, with Python and yt-dlp |
| `compose.yml` | Mounts your repository clone and runs the container |
| `.github/workflows/epg.yml` | Regenerates `public/guide.xml` on GitHub every 6 hours |

## Setup

1. Put these files (including the `playlist/` folder) in your repository clone. `compose.yml` mounts its own folder (`.`) as `/data`, so the playlist is written to `public/` inside it (the folder is created if missing). If you keep the files elsewhere, replace `.` with the absolute path of your clone.
2. Build the image:

   ```bash
   docker compose build
   ```

## How to run

```bash
docker compose run --rm playlist-generator
```

To test the possible official sources for La7, La7d, TV8, Cielo and Sky TG24 without writing anything:

```bash
docker compose run --rm playlist-generator --diagnose
```

It tries Sky's live APIs (and how long their tokens last), Sky's links without token, the stream links found on la7.it and known La7 links, with and without the la7.it Referer, and prints what works.

On Linux the file is written as user `1000:1000`. If `id -u` returns a different number, run:

```bash
PUID=$(id -u) PGID=$(id -g) docker compose run --rm playlist-generator
```

### Output

| Message | Meaning |
| --- | --- |
| `Updated: TV8` | Sky link refreshed |
| `Not updated: … (keeping the link from the previous run)` | yt-dlp found no new link; the one from the last run is kept |
| `Not updated: … (keeping the link from the upstream playlist)` | No new link and no previous run; the channel probably does not work |
| `  reason: ERROR: …` | Printed under each "Not updated" line: the error reported by yt-dlp |
| `Replaced: NOVE (ENOTFOUND) -> https://… [iptv-org]` | The upstream link did not answer; a working official link was used instead (`[RAI relinker]` or `[iptv-org]`) |
| `Not working, no official alternative found` | Channels whose link does not answer and that have no working official alternative; kept in the playlist, or removed with `REMOVE_NOT_WORKING=1` |
| `… unofficial alternative(s) ignored` | iptv-org had links for the channel, but only on third-party rebroadcast servers |
| `Links: 60 working, 8 replaced, 3 not working` | Summary of the link check |
| `Error: … The output file was not changed.` | Download failed or yt-dlp is missing; the file was not touched |

A link is "working" when it answers with an HLS (`#EXTM3U`) or DASH (`<MPD`) manifest within 10 seconds. iptv-org links are ignored when they are third-party rebroadcasts: hosts that are bare IP addresses or use a non-standard port, and servers that carry channels of different broadcasters (for example La7 and RAI on the same server), since an official server only carries its own broadcaster's channels. If a channel passes the check but Jellyfin still cannot play it, the problem is on the Jellyfin side (User-Agent, FFmpeg), not the link.

yt-dlp support is confirmed for the TV8 live stream; Cielo and Sky TG24 are not verified.

## Publish

```bash
cd /path/to/your/repo
git add public/iptvitaplus.m3u
git commit -m "Update playlist"
git pull --rebase
git push
```

If `git commit` says "nothing to commit", the playlist did not change. `git pull --rebase` fetches the guide updates committed by GitHub Actions first; without it the push may be refused.

## Automatic TV guide update

The workflow `.github/workflows/epg.yml` runs the `epg-generator` service (folder `epg/`) on GitHub's servers:

- every 6 hours (at minute 15, UTC);
- when you push to `main` a change to `public/iptvitaplus.m3u`, `compose.yml` or `epg/`;
- by hand, from **Actions → Update TV guide → Run workflow**.

It commits `public/guide.xml` as `github-actions[bot]` only if the file differs from the one in the repository. If the new guide has less than half the programmes of the current one, it commits nothing and the run fails; run it by hand with **force** ticked to commit it anyway. GitHub's servers are not in Italy, so a source may return fewer programmes than from your computer.

Since the workflow commits to `main`, do not commit a `guide.xml` generated on your computer: discard it with `git checkout public/guide.xml`.

## Use in Jellyfin

In **Dashboard → Live TV → Tuner Devices**, add an **M3U Tuner** with:

- **File or URL:** `https://raw.githubusercontent.com/<user>/<repo>/main/public/iptvitaplus.m3u`
- **User agent:** `HbbTV/1.6.1` (required by the RAI and Mediaset streams)

GitHub caches raw files for about 5 minutes, so changes may take a few minutes to show up after a push.

## Without Docker

With Node.js 18+ and yt-dlp installed (`pip install -U yt-dlp`):

```bash
node playlist/generate-playlist.js /path/to/your/repo/public
```

## Configuration

| Variable | Default | Description |
| --- | --- | --- |
| `OUTPUT_DIR` | `/data/public` | Output folder inside the container |
| `SOURCE_URL` | Tundrak `iptvitaplus.m3u` | Upstream playlist to start from; its file name is used for the output |
| `ALT_SOURCE_URL` | iptv-org `streams/it.m3u` | Playlist the replacement links are taken from |
| `USER_AGENT` | `HbbTV/1.6.1` | User-Agent used to check the links; keep it equal to the one set on the Jellyfin tuner |
| `CHECK_STREAMS` | `1` | Set to `0` to skip the link check |
| `REMOVE_NOT_WORKING` | `0` | Set to `1` to leave out of the playlist the channels whose link does not work |
| `PUID` / `PGID` | `1000` | User and group that own the generated file (Linux) |

## Notes

- The repository is public: anyone can see the playlist, Sky links with their tokens included.
- If a Sky channel stays "Not updated", it is still available over digital terrestrial TV (Cielo on 26, Sky TG24 on 50).
